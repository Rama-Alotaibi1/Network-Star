Limitations
  • The notebook’s masking covers emails and Saudi mobile numbers written as 05XXXXXXXX. National IDs, IBANs, names and spaced phone numbers are not masked, which this page flags when it spots them.
  • All data is a small hand-written sample. Scores are illustrative, not benchmark results.
